# 管理后台前端 API 接口清单

> 按功能域分类，只列前端需要关心的接口
> 前端直连各微服务，读写操作统一走 Gateway 直通微服务
> 2026-07-19

---

## 一、接口分类原则

| 分类 | 说明 |
|------|------|
| **微服务直连** | 前端通过 `/api/{微服务}/v1/xxx` 调用 Gateway，直通微服务，返回 `ApiResult` |
| **读操作** | 前端直接调用各微服务的查询接口，返回 `ApiResult` |

不在列表中的接口：字典管理、定时任务、内部 Feign 接口等纯技术接口，前端无需关心。
