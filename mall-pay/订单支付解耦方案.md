# 订单-支付解耦方案

> 日期：2026-08-05（已更新：2026-08-08）
> 目的：将 Order 和 Pay 解耦为独立服务，MQ 负责异步状态同步
> 状态：**Step 1-4 已完成，BFF 已移除，前端直连后端**

---

## 当前流程（BFF 已移除后）

```
前端
  │
  ├─① GET /api/pay/v1/mobile/pay/channels   → Pay 返回可用渠道列表
  │
  ├─② 用户选渠道
  │
  ├─③ POST /api/order/v1/mobile/trade/submit → Order 返回 orderId + payAmount
  │
  ├─④ POST /api/pay/v1/mobile/pay/create    → Pay 返回 payOrderNo + prepayParams
  │
  └─⑤ 前端拿 prepayParams 拉起 SDK
```

**支付单的 create 由前端发起**——订单下单后，前端单独调 Pay 的 C 端接口拿 prepayParams。

```
    ┌──────────┐         ┌──────────┐
    │  Order   │         │   Pay    │
    │ 服务     │         │  服务    │
    └────┬─────┘         └────┬─────┘
         │                    │
         │   MQ(支付成功)      │
         │◄───────────────────┤  PaySuccessConsumer → 改订单状态
         │                    │
         │   MQ(关单通知)      │
         │◄───────────────────┤  Pay CLOSED → 释放库存（兜底）
         │                    │
         │   无直接 Feign 调用  │
         └────────────────────┘
```

**Order 不再通过 Feign 调用 Pay**，两边只靠 MQ 做异步状态同步。

---

## 三、超时机制

Order 超时是**主逻辑**，Pay 超时是**安全兜底**。

| 超时 | 谁触发 | 过期时间 | 做什么 |
|------|:---:|:---:|------|
| Order 超时（主） | `sendTimeoutCancelMessage` 延时 MQ | ≤30min | 取消订单 + 释放库存（不再关 Pay——Order 不存 payOrderNo） |
| Pay 超时（兜底） | `PayOrderCloseJob` 每 10 分钟 | 30min | 关支付单 → 渠道 close → MQ CLOSED → Order 释放库存 |

正常情况下 Pay 超时不会走到——Order 先过期就取消了订单。Pay 超时只在 Order 侧挂了的情况下兜底。

## 六、接口清单（当前态）

### 支付服务

| 路径 | 调用方 | 说明 |
|------|------|------|
| `GET /v1/mobile/pay/channels` | 前端(经Gateway) | 可用渠道列表 |
| `POST /v1/mobile/pay/create` | 前端(经Gateway) | 创建支付单+拿prepayParams |
| `POST /v1/mobile/pay/query` | 前端(经Gateway) | 轮询支付结果 |
| `GET /v1/internal/pay/channels` | 内部Feign | channels |
| `POST /v1/internal/pay/create` | 内部Feign | 创建支付单 |
| `POST /v1/internal/pay/query` | 内部Feign | 查询 |
| `POST /v1/internal/pay/close` | 内部Feign | 关闭 |
| `POST /v1/notify/alipay` | 支付宝 | 回调 |
| `POST /v1/notify/wechat` | 微信 | 回调 |
| Admin CRUD 8 个 | admin 前端 | 配置/查询 |

### 订单服务

| 路径 | 调用方 | 说明 |
|------|------|------|
| `POST /v1/mobile/trade/submit` | 前端(经Gateway) | 提交订单，返回 orderId + payAmount |
| `POST /v1/mobile/trade/*` | 前端(经Gateway) | 订单 CRUD |
| `POST /v1/internal/trade/getDetailByCode` | Pay(回调) | 反查订单详情 |
